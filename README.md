# Xiaroo - AI-Powered Software Development Company

**Xiaroo** is a modern, futuristic website for an AI-powered software development company built by a Gen Z team. The site showcases cutting-edge web and mobile app development, AI solutions, and scalable digital platforms.

🔗 **Live Demo:** [https://xiaroo.com](https://xiaroo.com)

## 🚀 Getting Started

To get started locally:

1. **Install dependencies**

   ```sh
   npm install
   # or
   yarn install
   ```

2. **Start the development server**

   ```sh
   npm run dev
   # or
   yarn dev
   ```

   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Build for production**

   ```sh
   npm run build
   npm start
   # or
   yarn build
   yarn start
   ```

## 🛠️ Customization

### **Brand Colors**
Update colors in `tailwind.config.ts`:
```typescript
brand: {
  dark: "#132442",
  orange: "#fe701c",
  // ... other variants
}
```

### **Content Updates**
- **Hero Section:** Update messaging in `components/hero.tsx`
- **Services:** Modify services in `components/features.tsx`
- **Portfolio:** Update projects in `components/work.tsx`
- **Contact Info:** Change contact details in `components/contact.tsx`

### **SEO Configuration**
Update metadata in `app/layout.tsx`:
- Company information
- URLs and canonical links
- Social media links
- Structured data
